# Support

## Before Opening an Issue

Check the relevant documentation first:

- [Installation](docs/en/installation.md)
- [Configuration](docs/en/configuration.md)
- [Troubleshooting](docs/en/troubleshooting.md)

## Include

- DocMeThis Fix facade revision or release record.
- Full private runtime commit SHA and artifact SHA-256 when applicable.
- DocMeThis Check, Extract and Verify versions.
- Python version, operating system and architecture.
- Workflow event and relevant non-secret configuration names.
- The sanitized Check summary and Fix result status.
- A minimal reproducible example that contains no customer source or secrets.

## Never Include

- API keys, bearer tokens, Gateway credentials or private distribution tokens.
- Prompts, generated private configuration or unredacted request payloads.
- Customer source code or complete private Fix logs.

For security reports, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
